# Seções salvas

Partes do site guardadas para usar de novo. Cada pasta tem:

- `PROMPT.md`: o prompt completo da seção, com o código embutido. Mande esse arquivo e a seção volta para o site.
- `video/`: a seção gravada em mp4.
- `script/`: a seção em código independente, que abre direto no navegador.
